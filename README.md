# にほんご道場 — 일본어 N5 도장

JLPT N5 수준의 일본어를 하루 5분씩 익히는 웹 게임입니다. 설치 없이 브라우저에서 바로 실행됩니다.

## 담긴 것

- **문자 트랙** — 히라가나 118자(기본·탁음·요음), 가타카나 69자 · 7유닛 35레슨
- **어휘 트랙** — N5 단어 384개, 문장 128개 · 16유닛 80레슨
- 두 트랙은 서로 독립적으로 열려서, 가나를 이미 알면 단어부터 바로 시작할 수 있습니다
- **문제 유형 5가지** — 4지선다, 듣고 고르기, 짝 맞추기, 가나 입력, 문장 배열
- **간격 반복 복습** — 항목별로 1·3·7·21·60일 간격을 관리해 복습할 때를 알려줍니다
- **문법 카드** — 유닛마다 조사·활용 설명과 예문
- **진행 상황 백업** — 진도를 코드 한 덩어리로 뽑아 다른 기기에서 복원

## 구조

`index.html` 한 파일이 전부입니다. 빌드 과정도, 외부 의존성도 없습니다.
효과음과 배경음악은 Web Audio API로 그때그때 합성하고(요나누키 음계),
음성은 브라우저의 SpeechSynthesis를 씁니다.
진행 상황은 브라우저의 localStorage에 저장됩니다.

## 로컬에서 실행

```
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다.
